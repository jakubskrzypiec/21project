# 21project — frontend GitHub Pages

Ta wersja jest w 100% statyczna i nadaje się do GitHub Pages.

## Wdrożenie
1. Usuń z repo poprzednie pliki backendu/admina.
2. Wgraj zawartość tego ZIP-a do głównego katalogu repo.
3. W GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Zostaw plik `CNAME` z `21project.pl`.
5. Po publikacji sprawdź `https://21project.pl/robots.txt` i `https://21project.pl/sitemap.xml`.
6. W Google Search Console wyślij ponownie sitemapę: `https://21project.pl/sitemap.xml`.

## Co jest w wersji
- jasny frontend biały + niebieskie/czarne akcenty
- homepage z krótką treścią
- portfolio desktop/mobile
- 5 osobnych case studies
- oferta 1500 / 2500 / 3000 / SEO 1000
- proces współpracy
- sekcja SEO + wyszukiwanie AI
- JSON-LD / FAQ / robots / sitemap / llms.txt

`llms.txt` jest dodatkiem pomocniczym i nie gwarantuje widoczności w żadnym systemie AI.
