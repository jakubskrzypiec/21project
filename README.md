# 21project — landing page

Gotowa strona statyczna do wgrania na GitHub Pages.

## Publikacja

1. Wgraj całą zawartość tego folderu do głównego katalogu repozytorium `jakubskrzypiec/21project`.
2. Nie usuwaj pliku `CNAME` — odpowiada za domenę `21project.pl`.
3. Po publikacji prześlij w Google Search Console adres: `https://21project.pl/sitemap.xml`.
4. Przy pierwszym wysłaniu formularza FormSubmit wyśle na `jakubskrzypiec.dev@gmail.com` wiadomość aktywacyjną. Kliknij potwierdzenie tylko raz.

## Google Analytics

Strona ma gotowy mechanizm zgody cookies. Aby uruchomić GA4, wpisz identyfikator pomiaru w `index.html`:

```html
<html lang="pl" data-ga-id="G-XXXXXXXXXX">
```

Bez identyfikatora żaden skrypt analityczny nie jest pobierany.
