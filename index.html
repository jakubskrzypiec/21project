Jak uruchomić panel

1. Skopiuj .env.example do .env.
2. Wygeneruj hash: npm run hash-password -- "TwojeHaslo" i wklej do ADMIN_PASSWORD_HASH.
3. Ustaw długi SESSION_SECRET.
4. Uruchom npm install, potem npm start.

Do produkcji polecam Render/Railway/VPS z trwałym dyskiem dla SQLite. Na czystym GitHub Pages panel i backend nie zadziałają.

Prospecting

Analiza domen sprawdza publiczny HTML strony po backendzie: rok stopki, HTTPS, viewport, title, description, Schema.org i canonical. To szybki screening, nie pełny audyt SEO.

Powiadomienia e-mail

Jeśli wpiszesz RESEND_API_KEY, NOTIFY_EMAIL i FROM_EMAIL w .env, nowe formularze mogą wysyłać powiadomienie. Bez klucza lead i tak trafia do panelu.
