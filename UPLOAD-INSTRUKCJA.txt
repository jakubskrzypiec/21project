21PROJECT — WAŻNE PRZY WRZUCANIU NA GITHUB

W repo ma być TYLKO JEDEN plik index.html w katalogu głównym.
Podstrony muszą zostać w swoich folderach, np.:
- strony-internetowe-katowice/index.html
- strony-internetowe-slask/index.html
- strony-internetowe-dla-architektow/index.html
- pozycjonowanie-stron/index.html
- realizacje/index.html

NIE przenoś wszystkich plików index.html do jednego katalogu. Windows wtedy robi index (1).html, index (2).html itd. i strona się rozsypuje.

Najbezpieczniej: sklonuj repo lokalnie / otwórz je w GitHub Desktop, usuń starą zawartość (nie folder .git), skopiuj CAŁĄ zawartość tej paczki razem z folderami, zrób commit i push.
